# Project Brief

## 제품

- 표시 이름: `CLEVER Driver`
- 저장소: `EVNSolution/clever-driver-app`
- 앱 식별자: `com.evnsolution.clever.driver`
- 대상: DSV 배송원
- 기존 제품: `CLEVER Routes`와 독립
- project-start: `EVNSolution/clever-change-control#240`
- bootstrap issue: `EVNSolution/clever-driver-app#1`

## 목적

배송원이 운영자의 앱 계정 사전 발급 없이 가입하고, DSV 배송원 정보가
준비되면 자신의 계정에 자동 연결된 배송 업무를 확인하며, 배송지 단위로
업무를 안전하게 재분배할 수 있는 iOS/Android 앱을 만든다.

## 확정된 제품 계약

1. 앱, 호스팅과 API 계약은 `CLEVER Routes`와 분리한다.
2. 계정 소유권은 이름과 SMS 인증 전화번호로 확인한다.
3. 배송원 정보가 없어도 가입할 수 있다.
4. 같은 이름과 인증 전화번호의 배송원 정보가 생기면 관리자 승인 없이
   자동 연결한다.
5. 한 배송지와 그곳의 모든 물품은 하나의 분할 불가능한 배정 묶음이다.
6. 반납된 묶음은 미배정 목록에 공개하고 서버 선착순으로 확보한다.
7. 특정 배송원 지정, 상대방 수락, 개별 물품 이동은 첫 버전에 포함하지 않는다.

## 첫 구현 범위

- 앱 런타임과 저장소 규약
- 이름과 전화번호 입력
- SMS 인증
- 미연결 계정 상태
- 자동 연결된 내 배송지 조회
- 배송지별 물품 조회
- 배송지 묶음 반납
- 미배정 배송지 묶음 확보
- 동시 확보 충돌 안내

각 기능은 DSV API 계약이 승인된 작업 단위에서 순차적으로 구현한다.

## 정본 경계

- DSV 서버: 계정 연결, 배송원, 배송지, 물품, 배정의 최종 권위
- 이 저장소: 배송원 모바일 UX와 앱 런타임
- `CLEVER Routes`: 기술 패턴 참고 대상이며 코드 또는 API 정본이 아님

## 미정 사항

- SMS 인증 제공업체와 비용·재전송 정책
- 로그인 유지, 기기 변경과 계정 복구
- 이름 정규화와 중복 일치 처리
- 배송 시작 이후 반납·확보 가능 여부
- 차량, 온도와 적재 조건에 따른 확보 자격
- 관리자 예외 처리와 감사 기록
