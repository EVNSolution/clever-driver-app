# Project Brief

## 제품

- 표시 이름: `CLEVER Driver`
- 저장소: `EVNSolution/clever-driver-app`
- 앱 식별자: `com.evnsolution.clever.driver`
- 대상: DSV 배송원
- 기존 제품: `CLEVER Routes`와 독립
- project-start: `EVNSolution/clever-change-control#240`
- bootstrap issue: `EVNSolution/clever-driver-app#1`

## 목적

배송원이 운영자의 앱 계정 사전 발급 없이 가입하고, DSV 배송원 정보가
준비되면 자신의 계정에 자동 연결된 배송 업무를 확인하며, 배송지 단위로
업무를 안전하게 재분배할 수 있는 iOS/Android 앱을 만든다.

## 네이티브 배포 계약

- CLEVER Driver는 iOS와 Android 네이티브 앱으로만 제공한다. 웹앱과 PWA는
  설치 대안이나 운영 폴백으로 만들지 않는다.
- Android 현장 파일럿은 Google Play internal testing으로 먼저 검증한다. 검증한
  동일 AAB만 production 후보로 승격하며 production 직전에 다시 빌드하지 않는다.
- Google Drive 직접 설치 APK와 Google Play AAB는 서명 체계가 다르다. 기존 Drive
  설치본은 Play 설치본으로 자동 업데이트되지 않으며 전환 시 삭제 후 재설치한다.
- iOS 현장 파일럿은 TestFlight 외부 테스트로 배포하고, 정식 운영은 검색과
  차트에 노출되지 않는 Unlisted App Store 배포를 사용한다.
- iOS Ad Hoc 빌드는 등록된 내부 QA 기기에서만 사용한다. 배송원 정식 배포나
  Apple Developer Enterprise 배포로 확장하지 않는다.
- Unlisted App 설치 링크를 가진 사람도 DSV 서버가 승인한 계정과 배송 권한이
  없으면 운영 데이터에 접근할 수 없다. 설치 링크는 인증이나 권한의 근거가 아니다.
- 첫 App Store 버전은 수동 릴리스로 제출하고, Unlisted 배포 승인 전에는
  공개 릴리스하지 않는다.

## 확정된 제품 계약

1. 앱, 호스팅과 API 계약은 `CLEVER Routes`와 분리한다.
2. 앱 계정은 로그인 아이디 또는 이메일 주소와 비밀번호로 인증한다.
3. 일반 로그인 화면에 회원가입 버튼을 함께 제공한다.
4. 가입 기본 입력은 이름, 휴대전화 번호, 로그인 아이디 또는 이메일 주소와 비밀번호다.
5. 서버는 이름과 정규화한 휴대전화 번호가 모두 정확히 같은 활성·미연결 DSV 배송원만
   계정에 연결한다. 일치 배송원이 아직 없으면 계정은 연결 대기 상태로 생성하고 이후
   로그인 때 다시 탐색한다.
6. 한 배송지와 그곳의 모든 물품은 하나의 분할 불가능한 배정 묶음이다.
7. 반납된 묶음은 미배정 목록에 공개하고 서버 선착순으로 확보한다.
8. 내 배송지 묶음은 같은 당일 배차 그룹의 다른 배송원에게 직접 전달할 수 있다.
9. 직접 전달은 상대 배송원의 수락 뒤에만 배정이 바뀌며, 개별 물품 이동은 포함하지 않는다.

## 첫 구현 범위

- 앱 런타임과 저장소 규약
- 로그인 아이디 또는 이메일 주소와 비밀번호 입력
- 이름과 휴대전화 번호 입력
- 미연결 계정 상태
- 자동 연결된 내 배송지 조회
- 배송지별 물품 조회
- 배송지 묶음 반납
- 미배정 배송지 묶음 확보
- 같은 배차의 다른 배송원에게 배송지 묶음 전달
- 동시 확보 충돌 안내

각 기능은 DSV API 계약이 승인된 작업 단위에서 순차적으로 구현한다. 현행 가입과
로그인 계약은 기본 운영 주소 `https://clever-route-api.cleversystem.ai`의
`/api/dsv/driver/auth/register`, `/api/dsv/driver/auth/login`으로 연결한다.
가입 요청은 이름, 휴대전화 번호, 로그인 아이디 또는 이메일 주소와 비밀번호만 전송한다. 앱은
localhost 또는 `127.0.0.1` 개발을 위한
`EXPO_PUBLIC_DSV_API_BASE_URL` 재정의를 제외하고 HTTPS 주소만 허용한다.

인증 응답의 access token과 계정 연결 상태는 화면 메모리에만 유지한다.
30일 refresh token과 만료 시각은 Expo SecureStore에 저장하여 앱 재실행 시
`/api/dsv/driver/auth/refresh`로 자동 로그인한다. 로그아웃 또는 세션 만료 시
기기 저장 세션을 삭제하며 비밀번호는 저장하지 않는다.

웹과 서버의 배송원 가입 작업은 독립 워크트리에서 운영 검증을 마친 뒤 최종
완결 시 전체 변경을 스쿼시 머지하고 워크트리를 제거한다. 운영 검증 중에는
해당 워크트리를 유지한다.

## 내부 화면 범위

연결된 배송원으로 로그인한 뒤에는 두 화면만 제공한다.

1. `배송`: 주문을 배송지별 목록으로 확인하고, `순서 편집`에서 같은 배송지 ID의
   주문 전체를 함께 이동한다. 배송지 묶음은 배정 변경과 순서 편집의 단위다.
   지도 미리보기와 목록을 함께 스크롤하고 지도를 접어 편집 공간을 확보할 수 있다.
   핸들 드래그 또는 위·아래 버튼으로 순서를 변경한다. `주문 목록` 하위 페이지에서는 `내 배송`의 배송지
   전체 묶음을 반납하거나 같은 배차의 다른 배송원에게 전달하고, `공용 배송`의
   묶음을 서버 선착순으로 확보한다.
2. `지도`: 같은 순서를 MapLibre 지도 위의 번호로 확인하고, DSV 서버가
   OSRM/VWorld로 생성해 제공한 경로 geometry가 있을 때만 경로 선을 표시한다.
   서버가 제공한 출발지 좌표를 별도 마커로 표시하고, 하단에는 서버 ETA가
   지정한 다음 배송지의 이름·주소, 주문 수, 박스 수와 ETA를 표시한다. 서버가
   제공한 도착 시간창, 온도 조건과 배송 메모가 있으면 지도 상단에 주의 정보로
   표시한다. 지도 화면을 보고 있는 동안에는 사용 중 위치 권한으로 배송원의
   현재 위치와 정확도·방향을 표시하며 백그라운드 위치는 수집하지 않는다. 지도
   열기는 주소를 먼저 복사한 뒤 Android의 설치된 지도 앱 선택기를 연다. 배송
   완료는 운행 시작 이후 서버 `STOP_DELIVERED` 이벤트로 기록한다. 완료 처리
   뒤에는 카메라 촬영 또는 앨범 선택으로 사진 증빙을 미리 보고 해당 배송지에
   업로드할 수 있다. 상단 환경설정에서는 위치·카메라·사진 앨범 권한 상태를
   확인하고 권한 요청 또는 기기 앱 설정으로 이동할 수 있다. 앱이 제공하는
   확인·경고·성공·오류 팝업은 CLEVER Driver 공통 다이얼로그를 사용하며 Android
   기본 Alert는 사용하지 않는다. OS 권한 창과 외부 앱 선택기는 시스템 UI를
   그대로 사용한다.

배송 목록은 계정 토큰으로 `/driver/route-access/lookup`을 조회한 뒤 서버가
발급한 경로 범위 토큰으로 `/driver/assigned-route`를 조회해 표시한다. 화면의
배송일은 기기 날짜가 아니라 응답의 `deliveryDate`를 사용한다. 앱은 배송지
좌표를 임의로 연결하거나 경로를 계산하지 않으며, 서버의 `routeGeometry`가
있을 때만 그 좌표를 수정 없이 표시한다. 순서 저장은 별도 API 계약이 승인된
뒤 연결한다.

주문 목록은 같은 경로 범위 토큰으로 `/driver/delivery-space`를 조회하고,
배송지 ID와 서버 버전만 반납·확보 명령에 전달한다. 직접 전달 요청은 서버가 같은
배차 그룹에서 제공한 대상 배송원 ID만 추가로 전달하며, 대상 배송원이 수락하면 서버가 대상 경로를 결정한다.
현재 배송원·고객사·경로 범위는 토큰에서만 결정하며 앱 요청 본문으로 덮어쓰지 않는다. 차량이 연결된 빈 배차도
날짜·배차 선택 대상으로 유지하여 공용 배송에 접근할 수 있게 하며, 차량이 없는
배차는 서버가 `VEHICLE_REQUIRED`로 차단한다.

## 정본 경계

- DSV 서버: 계정 연결, 배송원, 배송지, 물품, 배정의 최종 권위
- 이 저장소: 배송원 모바일 UX와 앱 런타임
- `CLEVER Routes`: 기술 패턴 참고 대상이며 코드 또는 API 정본이 아님

## 미정 사항

- 기기 변경과 계정 복구
- 배송 시작 이후 반납·확보 가능 여부
- 온도와 적재 조건에 따른 확보 자격
- 관리자 예외 처리와 감사 기록
